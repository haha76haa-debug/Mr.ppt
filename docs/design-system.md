# 设计系统：网格、字号、配色

一套 PPT 好不好看，80% 取决于「是否只有一套规则」。本文件把规则写成常量，
对应代码 `src/pptx_native/theme.py`。**换主题只换常量，不改版式。**

## 1. 画布与网格

* 画布 16:9：`13.333 × 7.5 in`（EMU：`12192000 × 6858000`）。
* 12 栏网格：边距 `margin = 0.72in`，栏间距 `gutter = 0.28in`。
* 内容宽度 `11.893in`，单栏 `0.727in`。

```
|← margin →| col0 |g| col1 |g| ... |g| col11 |← margin →|
```

取任意一段用 `theme.col(start, span) -> (x, w)`：

```python
x, w = theme.col(0, 6)     # 左半栏
x, w = theme.col(6, 6)     # 右半栏，两栏之间正好一个 gutter
x, w = theme.col(2, 8)     # 居中 8 栏
```

`col(0, 12)` 恰好等于 `(margin, content_width)`，测试里有断言。

**纵向节奏**（`layouts.py` 常量）：

| 位置 | 值 |
|---|---|
| 标题基线 | `TITLE_Y = 0.62` |
| 标题强调线 | `TITLE_Y + 0.80` |
| 内容区上沿 | `BODY_TOP = 1.82` |
| 内容区下沿 | `BODY_BOTTOM = 6.82` |
| 页码 | 右下 `SLIDE_H - 0.62` |

## 2. 字号阶梯

一页最多 4 级。字号从 `TYPE_SCALE` 取，不要手写裸值：

| key | pt | 用途 |
|---|---|---|
| `display` | 88 | 章节大序号 |
| `hero` | 44 | 封面主标题 |
| `h1` | 34 | 页面标题 |
| `h2` | 26 | 金句 / 大段强调 |
| `lead` | 20 | 导语、目录条目 |
| `h3` | 19 | 小标题、卡片标题 |
| `body` | 16 | 正文 |
| `small` | 13 | 辅助说明、图表标签 |
| `caption` | 11 | 注释、页码、数据来源 |
| `stat` / `stat_unit` | 46 / 16 | 关键数字 / 单位 |

行距：标题 1.0~1.1，正文 1.3~1.5，引用 1.45。中文正文不要超过 28 字/行。

**从参考图反推字号**：中文字形墨迹高 ≈ 字号的 0.72 倍。

```
size_pt ≈ ink_px × (13.333 / image_px_w) × 72 / 0.72
```

## 3. 颜色角色

只允许这些角色出现在版式代码里：

| 角色 | 默认 | 用途 |
|---|---|---|
| `primary` | `#0B52C4` | 主色：强调线、数字、关键形状 |
| `primary_dark` | `#12325F` | 深底、渐变起点 |
| `primary_light` | `#2E7BE8` | 渐变终点、次级高亮 |
| `accent` | `#E0A03C` | 唯一强调色（封面短线、关键数据） |
| `text` | `#1F2329` | 正文主色 |
| `muted` | `#6B7280` | 辅助信息 |
| `bg` | `#FFFFFF` | 页面底色 |
| `surface` | `#F2F6FC` | 卡片 / 分区底色 |
| `line` | `#DCE2EC` | 分隔线、表格线 |
| `on_dark` | `#FFFFFF` | 深底上的文字 |

规则：

* 一个页面用色 ≤ 3 个（主色 + 中性 + 1 个强调）。
* 同一含义永远用同一颜色；不要「这页红、下页蓝」。
* 强调色（accent）只给「最想让观众看的那一个东西」，一页最多一处。
* 半透明只用于叠加层（注释条 78~82%），不要给正文。

## 4. 主题预设

```python
Theme.blue()      # 经典蓝：工作汇报、答辩、通用
Theme.dark()      # 深海蓝：发布会、路演
Theme.minimal()   # 石墨 + 赤陶：极简、作品集、学术
Theme.warm()      # 暖赤陶：品牌、文化类
```

自定义：

```python
from dataclasses import replace
from pptx_native.theme import Theme

theme = replace(Theme.blue(), primary="0F6B5C", primary_dark="073B33",
                accent="D96C3F", font_title="Source Han Sans SC")
```

## 5. 字体

* 中文：微软雅黑（Windows 自带）/ 思源黑体（跨平台）。
* 英文与数字可以单配（如 `Arial` / `Inter`），但**中文与英文分两套 run 时要分别写字体**。
* 每个 run 都显式写 `latin / ea / cs` 三处（`styling.set_font` 已处理），不依赖主题继承。
* 正文不加粗；标题可加粗。强调用颜色或字号，不要靠下划线/斜体。

## 6. 间距

* 元素之间用 4 的倍数（0.08in 网格的粗粒度版）：0.12 / 0.2 / 0.28 / 0.4 / 0.6 in。
* 卡片内边距 ≥ 0.32in；卡片之间 ≥ 0.24in。
* 标题与内容之间留 0.4in 以上呼吸空间。
* 页面四周不要贴边：至少 `margin`。

## 7. 自检清单

- [ ] 一页只有 1 个主标题、1 个论点
- [ ] 字号不超过 4 级，且都来自阶梯
- [ ] 颜色不超过 3 个角色
- [ ] 所有元素落在 12 栏网格上
- [ ] 正文 ≥ 14pt（投影场合 ≥ 16pt）
- [ ] 没有贴边、没有重叠
