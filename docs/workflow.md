# 工作流：从一句需求到一份 deck

这份文档讲「做什么」，[SKILL.md](../SKILL.md) 讲「怎么做」。适用于任何主题的
PPT：工作汇报、课程答辩、路演、分享会、论文图表页、活动策划……

## 0. 需求澄清（5 个问题）

拿到任务先问清，别直接开做：

| 问题 | 影响 |
|---|---|
| 给谁看？（评审 / 客户 / 同学 / 领导） | 信息深度、术语密度 |
| 什么场合、讲多久？ | 页数（10 分钟 ≈ 8~12 页） |
| 投影还是发文件自己看？ | 字号（投影 ≥ 16pt；自读可 12pt） |
| 有没有既定模板 / 品牌色 / 字体？ | 是否复用 Theme |
| 有没有素材、忌讳、必须出现的页？ | 图片墙、免责声明、致谢页 |

同时确认：**要不要可编辑**。如果只要看图，导出图片最省事；只要可编辑，
就必须原生构建（见 [native-editing.md](native-editing.md)）。

## 1. 先写大纲，再碰设计

每条大纲 = 一句「这页要观众记住什么」，不是「这页要放什么」。

```
1  封面：季度回顾 / 2026 Q1
2  结论先行：交付准时率 96%，超目标 1 个百分点
3  背景：三条业务线并行，口径不统一
4  方法：统一指标 → 看板自动汇总 → 每周复盘
5  数据：4 个关键数字
6  里程碑：12 周计划
7  风险与下一步：2 个依赖项
8  结尾
```

检查：

- 前 3 页之内必须出现核心结论（评审没耐心）。
- 每页一个论点；一页讲超过 90 秒就拆。
- 每 3~5 页插一个过渡页（`section`），给观众换气。
- 最后一定有一页「下一步 / 需要的支持」。

## 2. 选择页面类型

按信息形态映射到 [layouts.md](layouts.md)：

| 要表达 | 用 |
|---|---|
| 一个结论 + 论据 | `bullets` |
| 两个方案/前后对比 | `two_col` |
| 3~5 个关键数字 | `stats` |
| 时间安排 | `timeline` |
| 步骤/方法 | `process` |
| 趋势/占比 | `chart` |
| 精确数值 | `table` |
| 现场照片/作品 | `image_grid` |
| 一句金句 | `quote` |

## 3. 定视觉系统

复制一段模板代码（见 [README](../README.md#在代码里用)），改三处：
主题预设、字体、强调色。系统定完再开始排页，避免返工。

## 4. 搭骨架

先只放标题和区块占位，从头翻一遍：

- 同样信息类型是否用同一种版式？
- 页面密度是否有节奏（密 → 疏 → 密）？
- 有没有连续 3 页都是纯文字？

## 5. 填内容 + 素材

* 文案：短句、动词开头、数字前置。每行 ≤ 28 个汉字。
* 图片：cover 裁切；截图不裁；去掉阴影。
* 图表：原生 chart；标题写结论（「Q4 交付创新高」而不是「季度趋势」）。
* 图标：形状 + 文字，不用 emoji。

## 6. 自检（每页 30 秒）

- [ ] 标题是结论，不是主题
- [ ] 文字没有溢出文本框 / 没有贴边
- [ ] 没有元素重叠（`pptx-native overlaps`）
- [ ] 字号 ≥ 14pt，正文 ≥ 16pt
- [ ] 颜色 ≤ 3 个角色
- [ ] 图片没有拉伸、没有留白边
- [ ] 页码 / 页脚一致

## 7. 真机校验

```bash
pptx-native export deck.pptx pN.png --slide N
```

用 PowerPoint 导出的图逐页看：3D 透视、文本描边、透明叠层、字体替换只有真机才准。
LibreOffice / 在线预览只用来快速发现溢出。

## 8. 交付

* 复制到用户指定位置，核对 `Length` / `LastWriteTime`。
* 交付说明写三件事：改了什么、怎么验证的、有什么已知限制。
* 保留源文件与构建脚本——下一版要能「从原始文件重跑」，不是在旧文件上打补丁。

## 9. 常见返工原因

| 返工 | 根因 | 预防 |
|---|---|---|
| 「太满了」 | 没控制信息量 | 一页一论点，先删后加 |
| 「不统一」 | 没先定系统 | 先 Theme 再排页 |
| 「图和字对不齐」 | 目测摆放 | 用网格 `col()` |
| 「颜色不对」 | 主题色残留 | 全量扫色（`colors`/`sweep`） |
| 「照片歪了」 | 组合 3D 透视 | 同组 / 真机校验 |
| 「打不开」 | 形状 id 重复 / 包损坏 | `preview` 抽页 + 重编号 |
