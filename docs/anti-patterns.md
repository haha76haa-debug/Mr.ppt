# 反模式对照表

「这么改就对了」比「不要这样」好记，所以每条给出对照。

## 内容

| ❌ 坏味道 | ✅ 改成 |
|---|---|
| 标题写主题：「项目进展」 | 写结论：「关键路径已跑通，风险在依赖项」 |
| 一页 200 字、5 个论点 | 一页一论点，其余拆页或进备注 |
| 大段项目符号，每级都缩进 | 最多一级；要点 3~5 个 |
| 数据堆满全页，没有重点 | 挑 3~5 个放大（`stats`），其余进表格/附录 |
| 目录写「第一部分」 | 目录写观众关心的内容 |
| 结尾只写「谢谢」 | 「谢谢 + 下一步 / 需要的支持 / 联系方式」 |
| 图表标题「季度趋势」 | 「Q4 交付创新高」 |
| 没有数据来源 | 页脚一行小字：来源 + 时间 |

## 排版

| ❌ | ✅ |
|---|---|
| 每页版式都不一样 | 同一种信息固定用同一种版式 |
| 元素目测摆放，边缘不齐 | 全部落在 12 栏网格上 |
| 标题与正文贴在一起 | 标题下留 ≥ 0.4in |
| 一页 6 种字号 | 4 级以内，取自字号阶梯 |
| 正文 10pt 塞满 | 投影 ≥ 16pt，自读 ≥ 12pt |
| 文本框贴页边 | 距边 ≥ 0.72in |
| 内容垂直居中在整页 | 内容区固定从 1.82in 开始，底部留白 |
| 页码忽左忽右 | 固定右下角 |

## 颜色与字体

| ❌ | ✅ |
|---|---|
| 5 种蓝、3 种红 | 主色 + 中性 + 1 个强调色 |
| 每页强调色不同 | 强调色全 deck 唯一 |
| 用红色表示「重点」 | 用主色 + 字号放大；红色留给「错误/警示」 |
| 中文用宋体/楷体混排 | 中文一套黑体（微软雅黑/思源黑体） |
| 依赖主题字体 | 每个 run 显式写 latin/ea/cs |
| 正文斜体、下划线强调 | 加粗或换色 |

## 图片

| ❌ | ✅ |
|---|---|
| 直接 `add_picture` 给宽高 → 拉伸 | 先 `images.cover` 裁到槽位比例 |
| 图片留白边 / 黑边 | cover 填满 |
| 给照片加阴影 / 模糊边 | 无效果，纯平 |
| 截图被裁掉正文 | `images.pad` 整图 + 背景补边 |
| 21 张图堆一页 | 图片墙 3×2 或 4×2，一页 ≤ 8 张 |
| 图片压在文字上 | 半透明注释条，不遮内容 |

## 图表 / 表格

| ❌ | ✅ |
|---|---|
| 3D 饼图、3D 柱 | 2D 柱 / 条 / 折线 |
| 纵轴不从 0 开始 | 柱状从 0 开始；折线可截断但标注 |
| 图例 5 项 | 图例 ≤ 3；更多就换图型或拆页 |
| 表格 8 列塞满 | ≤ 5 列，超出的列删/合并 |
| 表格用模板默认样式 | 显式清样式，主色表头 + 细下划线 |
| 柱子上没数字 | 单系列加数据标签 |

## 工程（做可编辑文件时）

| ❌ | ✅ |
|---|---|
| 截图贴进 PPT 当一页 | 原生形状 + 真文字 |
| 直接改 `shape.left` 当渲染坐标 | `geometry.abs_rect()` |
| 注释条放在组合外，照片在组内 | 同组继承变换 |
| 用 `bodyPr@vert` 做竖排 | 一字一段（`styling.vertical_label`） |
| 生成后只看 LibreOffice | PowerPoint 真机导出 |
| 改完不 diff | `pptx-native diff` |
| 在上一版 pptx 上反复打补丁 | 从原始文件重跑构建脚本 |
| 输出文件直接覆盖用户原件 | 复制成新文件，核对大小/时间 |
